Сервис в котором я смогу авторизовавшись добавлять в виде канбана или Pinterest досок видео с ютуба или любого другого видео-хостинга. Чтобы каждая колонка имела свой визуальный цветовой вид. В открытой части я хочу выводить данные канбан плитки (с видео) в видео сетки подобно тому, как это сделано на Pinterest.   • Rutube oEmbed: CORS на живом сайте не проверен (в моём окружении тест был через IAB; при неудаче — fallback noembed/вручную). VK и Dzen автоматически не резолвятся.
  • Токен в localStorage уязвим к XSS; на статическом сайте без сторонних скриптов риск низкий, документировано в README.
  • GitHub Pages кэширует до ~10 минут — после коммита контент обновляется с задержкой; владельцу данные всегда отдаются свежие через Contents API.
  • Токену нужен именно Contents: Read and write на этот репозиторий — иначе 403 с внятной подсказкой в модалке входа.

Запрос пользователя

А можем дизайн сделать в монохромном стиле?

Что сделано

  • Весь интерфейсный хром переведён в монохром: --accent #4a9eff → #d9d9d9 (светло-серый), кнопки «Добавить видео»/primary — инвертированные (светлый фон, тёмный текст), ссылки/теги/фокус-ринг/drop-индикатор/тосты (кроме сигнальной ошибки) — серые.
  • Превью (галерея, канбан, превью в редакторе) — grayscale(1) contrast(1.04) по умолчанию, цвет проявляется при наведении на карточку и по переключателю — точный паттерн PinRefBoard (body.color .card img { filter:none }).

  • Цвета колонок в моно-режиме переводятся в различимые оттенки серого по яркости (hexToGray, luminance с клампом 100–200) прямо при рендере: полосы карточек, точки/тинты шапок колонок, чипы колонок, точки в меню переноса. В цветном режиме — исходные цвета. Палитра в редакторе колонок остаётся цветной (выбор цвета), видео в плеере — всегда цветное.
  • Кэш-бастинг поднят до ?v=2 (css, app.js).

  • index.html — кнопка #color-toggle в шапке, версии ?v=2
  • js/app.js — COLOR_KEY, hexToGray/monoColor (luminance→серый), state.color, applyColorMode, обработчик переключателя, monoColor во всех местах вывода --c/цветов меню

Как проверить

  • node tools/dev-server.mjs → http://127.0.0.1:8940/ — по умолчанию монохром; кнопка-полукруг в шапке включает цвет (сохраняется после перезагрузки); в канбане колонки различимы оттенками серого; наведение на карточку проявляет цвет превью.

Решения и допущения

  • Выбран паттерн «моно по умолчанию + показать цвет» (как у PinRefBoard), а не полное обесцвечивание: цвет колонок — исходное требование пользователя из ТЗ, переключатель сохраняет обе возможности.

  • Сигнальные цвета (ошибка в тосте/валидации, зелёный авторизации, палитра-пикер) оставлены цветными сознательно.

Открытые вопросы и риски
