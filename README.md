# PinVideoBoard

Витрина видео-досок на GitHub Pages: коллекция видео с YouTube / Vimeo / Rutube / VK и других хостингов в виде
Pinterest-подобной сетки с фильтрами и канбан-доски с цветными колонками и drag & drop.

Сайт полностью статический (ванильный JS, без сборки и зависимостей) — как соседний PinRefBoard.

## Возможности

**Публичная часть (всем посетителям)**
- Masonry-сетка карточек как в Pinterest: превью, название, длительность, провайдер, теги.
- Фильтры: вкладки досок (плейлистов), поиск по названию/тегам/заметке (`/` — фокус в поиск), провайдер, тег, сортировка.
- Канбан-вид доски (переключатель «Сетка ⇄ Канбан» в шапке) — просмотр колонок с цветами.
- Модальный плеер: размеры **30% / 50% / во весь экран** ширины окна, навигация ←/→ по отфильтрованным, Esc — закрыть.

**Редактирование (владелец, после входа)**
- Добавление плиток: вставьте ссылку на видео — название, превью и (если получится) длительность подтянутся автоматически.
  Не получилось — название всегда можно ввести вручную.
- Канбан: перенос карточек drag & drop между колонками и внутри колонки (на мобильных — меню карточки → «Переместить в …»).
- Колонки: добавить, переименовать, сменить цвет (палитра), удалить (видео переезжают в первую оставшуюся колонку).
- Доски: создать, переименовать, удалить.

## Как это устроено

- Данные — один файл [`data/db.js`](data/db.js) с глобальной переменной `window.__PVB_DATA`
  (доски → колонки → плитки). Он же раздаётся Pages всем посетителям.
- Сайт сам коммитит этот файл в репозиторий через GitHub Contents API (как [Prose.io](https://prose.io)):
  вход — персональный токен, коммит делается от вашего имени. Перед записью сравнивается `sha` файла;
  если данные менялись не из этого браузера, предложит «перезаписать / загрузить удалённые».
- Токен хранится **только в localStorage вашего браузера** и отправляется только на `api.github.com`.
  GitHub не разрешает браузерный OAuth-вход со статического сайта (CORS на `github.com/login/device/code`
  закрыт), поэтому вход — вставка токена.
- Метаданные видео: YouTube — превью напрямую с `i.ytimg.com` (без сети), название — noembed.com, затем
  скрытый плеер IFrame API (`getVideoData().title`); Vimeo — официальный oEmbed (CORS); Rutube — oEmbed;
  остальное — noembed → ручной ввод. Прямые ссылки на `.mp4/.webm` играются встроенным `<video>`.

## Публикация (GitHub Pages)

1. Создайте репозиторий **PinVideoBoard** на GitHub и запушьте ветку `main`
   (remote можно привязать потом: `git remote add origin https://github.com/Mmitekk/PinVideoBoard.git`).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save.
3. Проверьте `js/config.js`: `owner` и `repo` должны совпадать с вашим логином и путём репозитория.

## Вход владельца

1. Откройте [создание fine-grained токена](https://github.com/settings/personal-access-tokens/new):
   - Token name: `PinVideoBoard`; Expiration — на ваш вкус;
   - **Repository access → Only select repositories → PinVideoBoard**;
   - **Permissions → Contents → Read and write**;
   - Generate, скопируйте токен.
2. На сайте нажмите «Войти» и вставьте токен. Всё — кнопки добавления/редактирования активны.

Токен можно отозвать в любой момент в [настройках токенов](https://github.com/settings/personal-access-tokens).

## Локальная разработка (без токена)

```bash
node tools/dev-server.mjs
# → http://127.0.0.1:8940/
```

`DEV_MODE` в `js/config.js` разрешает сохранение **только на localhost** через `POST /api/dev-save`
этого сервера (пишет `data/db.js` локально, без коммитов). На GitHub Pages флаг инертен.

## Длительности видео

Бейдж длительности показывается на превью, если у плитки заполнено поле `duration`
(появляется автоматически при добавлении через «Определить»; для импортированных плиток его можно
дозаполнить):

```bash
node tools/fill-durations.mjs --commit          # заполнить отсутствующие длительности
node tools/fill-durations.mjs --workers 1 --delay 10000 --commit  # мягкий режим при «НЕ УДАЛОСЬ»
```

Длительность достаётся из страницы видео (без API-ключей). YouTube ограничивает частоту запросов
с одного IP: после ~40 быстрых запросов начинает отдавать пустые страницы. Если появилось много
«НЕ УДАЛОСЬ» — подождите 30–60 минут и перезапустите; плитки с уже заполненной длительностью
пропускаются, повторный запуск безопасен. Запуск передаёт результат одним коммитом.

## Структура

```
index.html          — страница (галерея, канбан, модалки)
css/style.css       — тёмная тема
js/config.js        — owner / repo / DEV_MODE
js/api.js           — GitHub Contents API: вход, чтение, запись, sha-guard
js/videos.js        — разбор ссылок + резолверы метаданных + embed-URL
js/app.js           — приложение: стейт, рендер, фильтры, DnD, модалки
data/db.js          — ДАННЫЕ (коммитятся сайтом)
tools/dev-server.mjs— локальный сервер для разработки
tools/fill-durations.mjs — заполнение длительностей YouTube
```

## Схема `data/db.js`

```js
window.__PVB_DATA = {
  version: 1,
  updatedAt: "ISO",
  boards: [{
    id: "b-…", name: "Основная", createdAt: "ISO",
    columns: [{ id: "c-…", name: "Смотреть позже", color: "#4a9eff" }],
    tiles: [{
      id: "t-…", columnId: "c-…",
      url: "https://…", provider: "youtube|vimeo|rutube|vk|direct|other",
      vid: "…", vk: { oid, id },
      title: "…", thumb: "https://…", duration: 0,
      tags: ["…"], note: "", addedAt: "ISO"
    }]
  }]
};
```
